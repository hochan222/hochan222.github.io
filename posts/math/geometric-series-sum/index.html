math 2025년 8월 4일

기하급수 합 공식 증명

수학 기하급수 증명

문제

기하급수(등비급수)의 합 공식을 증명합니다:

2^0 + 2^1 + 2^2 + ... + 2^n = 2^(n+1) - 1

이 공식은 알고리즘의 시간복잡도 분석에서 자주 사용됩니다.

일반적인 기하급수 합 공식

먼저 일반적인 기하급수 합 공식을 살펴보겠습니다.

공식: a + ar + ar² + ar³ + ... + arⁿ = a(1 - r^(n+1)) / (1 - r) (단, r ≠ 1)

여기서:

  • a: 첫 번째 항
  • r: 공비(common ratio)
  • n: 항의 개수 - 1

증명 1: 수학적 귀납법

기본 단계 (Base Case)

n = 0일 때:

  • 좌변: 2^0 = 1
  • 우변: 2^(0+1) - 1 = 2^1 - 1 = 2 - 1 = 1
  • 따라서 n = 0일 때 성립

귀납 단계 (Inductive Step)

n = k일 때 성립한다고 가정: 2^0 + 2^1 + 2^2 + ... + 2^k = 2^(k+1) - 1

n = k + 1일 때를 증명:

2^0 + 2^1 + 2^2 + ... + 2^k + 2^(k+1)
= (2^0 + 2^1 + 2^2 + ... + 2^k) + 2^(k+1)
= (2^(k+1) - 1) + 2^(k+1)  [귀납 가정 사용]
= 2^(k+1) - 1 + 2^(k+1)
= 2 × 2^(k+1) - 1
= 2^(k+2) - 1
= 2^((k+1)+1) - 1

따라서 n = k + 1일 때도 성립합니다.

증명 2: 대수적 방법

방법 1: 곱셈과 뺄셈 이용

S = 2^0 + 2^1 + 2^2 + ... + 2^n 이라고 하면:

S = 2^0 + 2^1 + 2^2 + ... + 2^n
2S = 2^1 + 2^2 + 2^3 + ... + 2^(n+1)

위 두 식을 빼면:

2S - S = 2^(n+1) - 2^0
S = 2^(n+1) - 1

방법 2: 일반 공식 적용

일반적인 기하급수 합 공식에 적용:

  • a = 2^0 = 1 (첫 번째 항)
  • r = 2 (공비)
  • n = n (항의 개수 - 1)
S = a(1 - r^(n+1)) / (1 - r)
S = 1(1 - 2^(n+1)) / (1 - 2)
S = (1 - 2^(n+1)) / (-1)
S = -(1 - 2^(n+1))
S = -1 + 2^(n+1)
S = 2^(n+1) - 1

증명 3: 이진수 관점

이진수로 표현하면 더 직관적으로 이해할 수 있습니다.

예시: n = 4일 때

2^0 + 2^1 + 2^2 + 2^3 + 2^4
= 1 + 2 + 4 + 8 + 16
= 31

이를 이진수로 표현하면:

31 = 11111₂

이는 n+1개의 1이 연속된 이진수입니다.

일반화

n개의 항을 더한 결과는 n+1개의 1이 연속된 이진수가 됩니다:

2^0 + 2^1 + 2^2 + ... + 2^n = 111...111₂ (n+1개의 1)

이 이진수를 십진수로 변환하면:

111...111₂ = 2^(n+1) - 1

알고리즘에서의 활용

재귀 알고리즘의 시간복잡도 분석

이 공식은 재귀 알고리즘의 시간복잡도를 분석할 때 자주 사용됩니다.

예시: Climbing Stairs 문제

재귀 트리에서 각 노드는 2개의 자식 노드를 가짐
트리 깊이가 n일 때 총 노드 수:
= 2^0 + 2^1 + 2^2 + ... + 2^n
= 2^(n+1) - 1
≈ 2^(n+1) (n이 클 때)

따라서 시간복잡도는 O(2^n)이 됩니다.

연습 문제

  1. n = 5일 때 계산

    • 2^0 + 2^1 + 2^2 + 2^3 + 2^4 + 2^5 = ?
    • 답: 2^6 - 1 = 64 - 1 = 63

  2. 일반화된 공식

    • 3^0 + 3^1 + 3^2 + ... + 3^n = ?
    • 답: (3^(n+1) - 1) / 2

  3. 부분합

    • 2^2 + 2^3 + 2^4 + ... + 2^n = ?
    • 답: 2^(n+1) - 2^2 = 2^(n+1) - 4
